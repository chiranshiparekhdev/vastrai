# VastrAI

AI-powered multi-tenant fashion commerce platform for Indian ethnic-wear retailers.

## Vision

VastrAI helps ethnic-wear retailers turn product images into AI-generated
fashion catalogs and provides customers with an AI-powered shopping assistant.

## Planned AI Capabilities

- Multimodal product understanding
- AI-generated fashion catalog images
- Product embeddings
- RAG-based product search
- AI shopping assistant
- LLM tool calling
- AI styling recommendations
- Marketing content generation
